SHAHRIYAR TOOLS Documentation

Welcome to the official user manual and documentation hub for SHAHRIYAR TOOLS. Every utility on this platform is built to run directly on your computer or phone with no server uploads.

1. Getting Started

SHAHRIYAR TOOLS provides fast, free, and completely private utilities for everyday web tasks. You can use every tool right away without signing up, installing any browser plugins, or paying any fees.

Instant Speed

Everything runs on your device hardware, meaning zero waiting for uploads or remote server queues.

Total Privacy

Your photos, sensitive PDF agreements, and passwords never leave your browser memory.

Mobile Friendly

Custom layouts designed specifically for touch screens, tablets, laptops, and desktop monitors.

2. Privacy & Security Architecture

Key Guarantee: No file you choose or generate is ever uploaded to a remote server. All image conversion, PDF splitting, compression, and password generation happen inside your device's memory.

Traditional websites require you to upload your personal files to their servers, where they may be stored, analyzed, or leaked. In contrast, SHAHRIYAR TOOLS uses modern Web Standards so that all calculations happen in your local browser sandbox.

3. Image & Media Tools

Image Compressor (/image-compressor/)

Compress JPG, PNG, and WebP images quickly while maintaining high visual quality.

  • Interactive Split Slider: Drag the center slider left and right to compare original vs. compressed quality in real time.
  • Quality & Resolution Sliders: Fine-tune compression percentage and scale down resolution (e.g. 50%, 75%) to achieve your target file size.
  • Batch Processing: Add multiple photos at once and download them individually or as a batch.

Batch Image Converter (/image-converter/)

Convert image formats easily between JPG, PNG, WebP, GIF, and BMP.

  • Select your desired output format from the dropdown menu.
  • Adjust quality settings for JPG and WebP files.
  • Download your converted images with one click.

Reunion Poster Studio (/reunionposter/)

A dedicated graphic studio for creating batch reunion, farewell, and event posters.

  • Choose from 8 distinct layout styles (Classic Centered, Split Sidebar, Top Banner, Scrapbook, Minimalist).
  • Select color palettes and canvas aspect ratios (Standard 3:4 portrait, 9:16 mobile story, 16:9 banner, or 1:1 square).
  • Double-click any text to edit dates, school names, and slogans.
  • Export high-resolution posters in up to 4K resolution.

4. PDF & Document Tools

PDF Toolkit (/pdf-tools/)

Manage and edit your PDF files securely:

  • Merge PDFs: Combine multiple PDF documents into a single organized file in seconds.
  • Split PDF: Extract specific page ranges (e.g., 1-5, 8, 11-14) into an independent PDF.
  • Rotate Pages: Fix sideways or upside-down scanned pages (90°, 180°, or 270°).
  • Extract Pages: Pull out only the single pages you need from long documents.

DuoVista PDF Studio (/duovista-pdf/)

An advanced dual split-screen PDF reader and study tool tailored for students, researchers, and examinees:

  • Up-Down (Top & Bottom) Split: Read an article or question passage on the top pane while independently viewing questions, diagrams, or notes below. Includes an ultra-thin 2px hairline divider.
  • Side-by-Side Split: Compare two documents or two separate sections of the same book on desktop or landscape displays.
  • Dual Document Mode: Load one single PDF across both panes, or open two completely different PDF files simultaneously.
  • IELTS & Exam Companion: Interactive Q1-40 answer sheet, scratchpad notes with instant local autosave, MP3 audio player for listening tests, and customizable countdown exam timers (20 min passage, 60 min full exam).
  • Edge-Style PDF Annotations: Multi-color highlighter, freehand ink pen, customizable text notes, and eraser tools right on the pages.
  • 100% Client-Side Privacy: Built on Mozilla PDF.js. All rendering and annotations run purely in your browser memory without uploading any files to external servers.

Passbook Studio (/passbook/)

A traditional Bengali customer ledger and passbook maker designed for merchants, small businesses, and cooperative societies.

  • Manage customer credit (বাকি) and debit (জমা) transactions.
  • Includes 12 bank-grade security border designs and authentic Bengali typography.
  • Print duplex booklets on standard A4 paper or export vector print sheets.

Invoice Generator (/invoice-generator/)

Create professional business invoices right in your browser. Add your business logo, custom line items, tax rates, and discounts. Click "Print / Save PDF" to generate an A4 invoice sheet instantly.

5. Developer & Security Utilities

QR Code Studio (/qr-code-generator/)

Create custom QR codes with high scanning reliability:

  • Supports Website URLs, Plain Text, Wi-Fi network credentials, Contact vCards, and Emails.
  • Custom foreground and background color pickers.
  • Optional center logo embedding with automatic white border backing.
  • Export as crisp high-resolution PNG or scalable vector SVG.

Password Generator (/password-generator/)

Create cryptographically strong passwords using your device's built-in random number generator. Includes password strength meters, estimated brute-force crack times, and customizable character rules.

JSON Formatter & Validator (/json-formatter/)

Clean up, format, and validate raw JSON code. Identifies exact line and column locations of syntax errors with helpful error hints.

Markdown Editor (/markdown-editor/)

Write documentation and articles with real-time side-by-side preview. Export clean HTML or raw Markdown files.

6. Everyday Calculators & Converters

Age Calculator (/age-calculator/)

Find your exact chronological age in years, months, and days. Features live ticking seconds, total days lived, and a countdown to your next birthday.

Unit Converter (/unit-converter/)

Convert measurements across 7 categories: Length, Weight, Temperature, Area, Volume, Speed, and Digital Storage.

Color Palette Studio (/color-palette/)

Generate harmonious color palettes, check WCAG contrast accessibility ratios for text readability, and create CSS gradients.
