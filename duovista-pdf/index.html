Why Students Choose DuoVista Dual Mode PDF Viewer

When solving IELTS Reading passages, academic research papers, or legal contracts, reading a passage on Page 1 while answering questions on Page 4 forces endless scrolling up and down. DuoVista PDF Studio solves this by displaying the same PDF in two independent Top-and-Bottom (Up-Down) or Side-by-Side panes.

  • 1 PDF Dual Split: Read the passage in the Top Pane and scroll questions independently in the Bottom Pane.
  • 2 Different PDFs Mode: Open the Question Paper on top and the Answer Key or Reference Book on the bottom.
  • Built-in Exam Suite: Includes an interactive Q1–40 IELTS Answer Sheet, Scratchpad, MP3 Audio Player, and Countdown Timer.

Windows 10 & Windows 11 Chrome / Edge Extension Guide

If you dragged & dropped the .crx file into Chrome or Edge on Windows 10 or Windows 11 and the toggle switch is greyed out ("This extension is not listed in the Chrome Web Store" or "CRX_REQUIRED_PROOF_MISSING"), use either 5-second fix:

  1. Best Method (Unpacked Folder — Never Blocked): Download DuoVista-Unpacked.zip, extract it, enable Developer mode in chrome://extensions or edge://extensions, and click "Load unpacked" (or drag the extracted folder onto the page). It turns ON immediately!
  2. 1-Click Windows 10/11 Admin Unlocker: Run Fix-Windows-10-11-Extension.bat inside the release bundle to automatically unpack to C:\DuoVista-PDF-Studio and unlock Windows Registry policies.

Frequently Asked Questions (FAQ)

How do I view the same PDF in Top-and-Bottom (Up-Down) split screen?

Click "Open Any PDF File" and choose your PDF. DuoVista automatically opens Page 1 in the Top Pane and subsequent pages in the Bottom Pane with an ultra-thin 2px hairline divider. Drag the divider to resize or double-click it to reset to 50:50.

How do I fix the CRX extension not turning ON in Windows 10 & Windows 11?

Windows 10 and Windows 11 block raw .crx files from turning on outside the Web Store. Remove the disabled CRX card, turn ON Developer mode, and click Load unpacked to select the extracted DuoVista-PDF-Studio folder (or run Fix-Windows-10-11-Extension.bat). Unpacked extensions turn ON immediately and never get disabled.

Does DuoVista PDF Studio work on Android phones, iPhones, and iPads?

Yes! You can open shahriyarsojibhasan.github.io/DUOVISTA-PDF-VIEWER in any mobile browser. The interface adapts automatically to phone and tablet screens with full touch scrolling, touch split-resizing, and mobile annotations.
